Technik erklärt

Von A bis Z — wie es funktioniert

Kein Black-Box-Versprechen. Hier ist, was passiert wenn jemand eine Frage stellt.

A
Frontend
Der Nutzer schreibt eine Frage
Das Chat-Widget läuft direkt auf eurer SBW-Website — keine externe App, kein Login. Der Nutzer tippt seine Frage im Browser.
🌐 HTML + CSS + JavaScript · gehostet auf chatfield-ai.ch (Vercel)
B
API-Aufruf
Nachricht geht an den Server
Mit einem HTTP-POST wird die Konversationshistorie (max. 12 Nachrichten) an unsere Serverless-Funktion übermittelt. HTTPS, verschlüsselt, kein Tracking.
📡 POST /api/sbw · JSON body · TLS 1.3 · keine Speicherung
C
System-Prompt
SBW-Wissen wird geladen
Jede Anfrage bekommt einen präzisen System-Prompt: wer SBW ist, welche Schulen es gibt, Standorte, Anmeldeprozesse — alles. Das ist das "Gehirn" des Assistenten.
📄 System-Prompt: ~800 Tokens SBW-Kontext · von Chatfield gepflegt
D
KI-Modell
Claude von Anthropic verarbeitet die Frage
Anthropic Claude — eines der leistungsfähigsten Sprachmodelle der Welt — generiert die Antwort. Entwickelt mit Fokus auf Sicherheit und Präzision.
🤖 Claude claude-haiku-3-5 · Anthropic API · Streaming aktiviert
E
Streaming
Antwort kommt Token für Token
Statt zu warten bis die ganze Antwort fertig ist, schickt der Server jedes Wort sofort über eine SSE-Verbindung. Das gibt das lebendige Schreibgefühl.
⚡ Server-Sent Events (SSE) · content_block_delta events · ReadableStream
F
Darstellung
Text erscheint im Widget
Das Frontend liest den Stream aus und fügt jeden neuen Text-Chunk direkt ins Chat-Bubble ein. Der Hase animiert sich — der Nutzer sieht eine lebendige Konversation.
🎨 DOM-Update per JS · bubble.textContent live geupdated · Avatar-Animation
